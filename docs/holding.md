# 💼 投资持仓管理 ᴾᴿᴼ

添加持仓管理为会员功能，需要[开通会员](https://help.fireapp.me/pro.html)。

投资持仓用于管理股票类投资资产，通过记录买入、卖出和分红送转，自动计算持仓数量、成本、市值和盈亏，无需手动维护资产余额，火记会根据行情价格T+1日更新余额。

## 添加持仓

![资产图片](/images/holding/holding1.png)

进入「股票」类资产详情页，点击右上角「记一笔」中的「添加持仓」：

* 搜索证券名称或代码（支持A股、港股、美股等市场，结果会标注所属市场）
* 选择投资品后填写买入价格、买入数量和手续费（手续费选填）
* 买入金额 = 数量 × 价格 + 手续费，保存后自动生成一笔「证券买入」账单

买入和卖出账单不计入收支统计，分红会计入收入。

## 添加交易

![资产图片](/images/holding/holding2.png)

点击持仓项进入持仓详情页，点击底部「添加交易」，选择「买入」「卖出」或「分红送转」，为该证券补充记账，证券已自动选定，无需再次搜索：

* 买入 / 卖出：填写交易价格、交易数量和手续费（手续费选填），买入金额 = 数量 × 价格 + 手续费，卖出金额 = 数量 × 价格 − 手续费
* 分红送转：填写现金分红金额和送股/转增数量，可只填其中一项，保存后自动拆分为两笔账单
* 交易日期默认为今天，不能选择未来日期，支持补录历史交易
* 表单还支持选择账本、币种、填写备注和添加图片；当行情币种与资产币种不一致时，保存时会弹窗确认折算汇率

交易保存后，持仓数量、成本和盈亏会自动更新；已保存的交易可在持仓详情页的交易记录中左滑修改或删除。

点击买入/卖出/分红/送转的记录，可查看具体的账单详情。

## 持仓总览

股票类资产详情页分为三个 Tab：

* **持仓**：展示当前持有的证券，包含名称/代码、市值、数量、昨收、成本、盈亏和收益率
* **已清仓**：已卖出的证券保留在此，展示总盈亏（已实现盈亏 + 现金分红）
* **流水**：为非证券交易类的其他账单，例如证券账户和外部资产的转入转出记录

## 持仓详情

点击持仓行可进入持仓详情页：

* 统计卡：持仓盈亏、持仓市值、现金分红、持仓数量、昨收、成本价、总手续费、持仓天数
* 交易记录：按时间倒序展示该证券的买入/卖出/分红记录，点击可查看账单详情，左滑可修改或删除
* 点击底部「添加交易」可直接为该证券记录买入、卖出或分红送转

删除某笔交易记录会同步影响持仓数量和成本；该证券的全部账单删除后，持仓行会自动消失。

## 价格与盈亏口径

* 现价、市值和持仓盈亏均按**上一交易日收盘价**计算，为 T-1 非实时数据，盘中保持不变
* 盈亏颜色遵循**红涨绿跌**：盈利为红色，亏损为绿色
* 离线状态下行情缺失时按成本价降级展示，持仓盈亏显示为 0
* 离线状态下无法获取行情，进入相关页面会提示检查网络

## 成本价口径

持仓详情页可切换成本价计算口径（双端共享，仅需设置一次）：

| 口径 | 成本价 | 盈亏展示 |
| --- | --- | --- |
| 摊薄成本价（默认） | (Σ买入金额 − Σ卖出净额 − Σ现金分红) ÷ 持仓数量 | 持仓盈亏 |
| 平均成本价 | 移动加权平均（含买入手续费），卖出不影响成本价 | 未实现盈亏 |

两种口径的差异说明可在持仓详情页点击成本价切换图标查看公式拆解。
