# 📈 资产和负债

资产写在最前面，因为我觉得是FIRE的基础，你有多少钱才能决定你能否FIRE，决定你以哪种方式FIRE。

当然，**资产也并不是现金**。

你需要好好盘点自己的资产，包括现金、存款、投资等。在这个过程中，你需要知道哪些是资产，哪些是负债。就如信用卡，它不是你的资产，是别人对你的授信，你使用的每一分钱，会在下一个账单日具象化，你其实在透支你的未来。

**我并不建议每个人都使用信用卡**。

## 新增资产

在资产页可以新增资产或者负债，资产负债会根据母类（例如现金类资产）归集汇总：

![资产图片](/images/asset/asset1.jpg)

资产类：
* 现金类资产：可以是储蓄卡、现金、微信钱包等类现金或者现金资产，它们的价值是可以直接转换为现金的。
* 充值类资产：可以是通过充值获得的资产，例如公交卡、会员卡等。
* 投资理财：可以是股票、债券、基金等金融资产。
* 应收：即借出的资金。
* 固定资产：房产、车产等固定资产。

负债类：
* 信用类资产：外部资产提供的授信额度，能在授信额度下提前透支，例如信用卡、花呗等。
* 应付：即借入的资金。
* 贷款：京东金条、微粒贷等信用类贷款，或房贷、车贷等固定资产类贷款。

每个资产填写内容或有不同，根据要求填写即可。

## 资产统计

资产列表上会根据母类进行归集汇总：

![资产统计图片](/images/asset/asset2.jpg)

资产上方会统计总资产、总负债和净资产，右侧对资产和负债进行分组，饼图展示资产负债情况。

## 资产类排序

净资产卡片上鼠标移入更多icon，在展示的「资产类排序」按钮上点击：

![资产类排序图片](/images/asset/asset3.jpg)

在资产类排序抽屉上，拖动资产类即可根据资产类进行排序：

![资产类排序抽屉图片](/images/asset/asset4.jpg)

## 资产排序

资产详情抽屉中鼠标移入「更多」按钮，在展示的「排序」按钮上点击：

![资产类排序图片](/images/asset/asset5.jpg)

在资产排序抽屉上，拖动资产项即可根据资产进行排序：

![资产排序抽屉图片](/images/asset/asset6.jpg)

## 资产隐藏

资产详情抽屉中鼠标移入「更多」按钮，在展示的「隐藏」按钮上点击。隐藏资产后，将无法在资产列表看到，也无法在记账页面选择，资产统计也会剔除隐藏的资产：

![资产隐藏图片](/images/asset/asset7.jpg)

可以通过净资产卡片中更多的「已隐藏资产」进入查看：

![资产隐藏图片](/images/asset/asset8.jpg)

已隐藏资产列表中点击资产项，展示的资产详情抽屉中鼠标移入「更多」按钮，在展示的「取消隐藏」按钮上点击即可取消资产隐藏：
