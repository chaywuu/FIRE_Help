# 🖼️ 账单图片

账单图片用于为每笔账单保留凭证，例如购物小票、外卖订单截图、发票照片等，方便日后对账和回顾。

在火记中，账单图片除了日常账单可以添加图片之外，退款可添加退款凭证、报销可添加报销凭证、借出借入可添加借贷凭证、证券交易可添加交易凭证...

## 图片容量

* 非会员限制账单图片容量为500M，所有账单的账单图片都共享这个容量额度，容量的查询入口为：设置 → 账号管理 → 图片存储
* 会员账单图片容量为无限

![账单图片](/images/bill_image/bill_image1.png)

## 图片压缩

* 非会员上传账单图片会对图片进行压缩，压缩比例为70%。如果按照单张原始图片5M进行计算，大概能上传2000张图片
* 会员账单图片上传则不做压缩，原图上传


## 数量与大小限制

* 每笔账单最多支持 **5 张** 图片
* 单张图片不能超过 **10MB**

## 查看图片

* 账单列表中，有图片的账单会在卡片下方显示缩略图
* 点击账单卡片打开账单详情，点击图片可以全屏查看

## 上传与同步

* 保存账单后，图片会在网络可用时自动上传，无需手动操作
* 图片上传失败不会影响账单本身，应用会在后续自动重试
* 删除账单时，账单图片会一并删除
* 多端使用时（App 与网页版），任意一端上传的图片都会自动同步到其他端
