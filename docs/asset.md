# 📈 资产和负债

资产写在最前面，因为我觉得是FIRE的基础，你有多少钱才能决定你能否FIRE，决定你以哪种方式FIRE。

当然，**资产也并不是现金**。

你需要好好盘点自己的资产，包括现金、存款、投资等。在这个过程中，你需要知道哪些是资产，哪些是负债。就如信用卡，它不是你的资产，是别人对你的授信，你使用的每一分钱，会在下一个账单日具象化，你其实在透支你的未来。

**我并不建议每个人都使用信用卡**。

## 资产状态说明

非会员可启用10个资产和负债，超过10个则需要[开通会员](https://help.fireapp.me/pro.html)。

被禁用的资产依然可以被看到、被统计，只是无法再被使用了，就像是被「冻结」了。

资产被冻结的期间，数据都是正常的，等到「解冻」后，数据会正常使用。

## 新增资产

在资产页可以新增资产或者负债，通过点击右上角的「+」按钮，在选择资产类型抽屉中选择对应的资产类型：

![资产图片](/images/asset/asset1.png)

资产类：
* 现金类资产：可以是储蓄卡、现金、微信钱包等类现金或者现金资产，它们的价值是可以直接转换为现金的。
* 充值类资产：可以是通过充值获得的资产，例如公交卡、会员卡等。
* 投资理财：可以是股票、债券、基金等金融资产。
* 应收：即借出的资金。
* 固定资产：房产、车产等固定资产。

负债类：
* 信用类资产：外部资产提供的授信额度，能在授信额度下提前透支，例如信用卡、花呗等。
* 应付：即借入的资金。
* 贷款：京东金条、微粒贷等信用类贷款，或房贷、车贷等固定资产类贷款。

每个资产填写内容或有不同，根据要求填写即可。

## 资产币种

每个资产都会有独立的资产币种，资产中发生账单会根据账单币种与资产币种的汇率计算对资产的影响。

例如在人民币资产中是有可能发生美元交易的，例如人民币的资产（例如储蓄卡）在美元的购物网站上发生了一笔100美元的交易，那么资产中会记录100美元的账单流水，对这个人民币资产的影响则会换算成人民币进行计算。

## 是否计入总资产

在新增和修改资产页面可对「计入总资产」进行开关设置，关闭状态下该资产余额不会被计入总资产。

## 资产统计

火记提供3种不同的视角去核对自己的资产负债情况：

![资产统计图片](/images/asset/asset2.png)

1. 净资产净值维度：在资产tab页的顶部，会展示总资产、总负债和净资产。
2. 净资产趋势维度：点击右上角的统计icon，进入统计页。统计页中展示了总负债、总资产和净资产的趋势。
3. 资产分布维度：净资产趋势图下方有资产分布图，是对每项资产的饼图可视化，展示了每项资产大类的占比。
