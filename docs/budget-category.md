# 🗂️ 分类预算 ᴾᴿᴼ

分类预算为会员专属功能，需要[开通会员](https://help.fireapp.me/pro.html)。非会员点击分类预算时会弹出升级引导。

分类预算针对单个支出分类设置预算额度，与[总预算](/budget)相互独立，在预算页的分类预算列表中管理。

## 分类预算列表


列表按支出分类逐行展示，每行包含分类图标、名称、使用进度条和预算信息：

* 未设置预算的分类显示「预算：未设置」
* 已设置预算的分类显示「预算：xx」和当期「已用：xx」
* 支出超过预算时，「已用」替换为「超支：xx」提示
* 尚未设置任何分类预算时，列表显示「暂无分类预算」

## 编辑分类预算

点击分类行即可设置该分类的预算金额：

* 无二级分类的分类：在底部抽屉中输入金额，保存后立即生效
* 有二级分类的一级分类：点击进入分类预算明细页，分别管理一级和二级分类预算

## 分类预算明细页

![预算图片](/images/budget/budget2.png)

明细页展示一级分类预算卡和二级分类预算列表：

* 一级、二级分类均可单独点击设置预算金额
* 点击右上角合并图标，可将二级分类预算的总和一键设置为一级分类预算
* 一级分类的已用仅统计直接记录在该分类下的账单，二级分类的已用按各自分类统计，互不重复计算
