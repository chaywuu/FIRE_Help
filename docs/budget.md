# 📅 总预算

预算页由总预算卡和分类预算列表组成，预算数据按当前账本独立统计。本篇介绍总预算，分类预算的设置见[分类预算](/budget-category)。

## 编辑总预算

点击头部中间的日期，可在底部抽屉中切换月份或年份：

* 选择具体月份：统计当月的预算使用情况
* 仅选择年份：切换为年视图，统计整年的预算使用情况

![预算图片](/images/budget/budget1.png)

点击总预算金额或金额右侧的编辑图标，在底部抽屉中输入金额后保存即可生效。


## 总预算卡

总预算卡展示当前账本的总预算和使用情况：

* 未设置总预算时，金额位置显示「未设置」
* **已用**：当前范围内计入预算的支出合计
* **可用**：总预算减去已用；支出超过总预算时显示「超支」及超支金额
* 右上角为当前账本入口，点击进入账本管理，可切换或新增账本

## 合并预算

点击金额右侧的合并图标，可以把已设置的分类预算总和一键设置为总预算：

* 确认弹窗中会展示分类预算总和，确认后写入总预算
* 尚未设置任何分类预算时，会提示「暂无分类预算可合并」

## 预算日历

点击头部右上角的日历图标进入预算日历：


* 点击顶部年份切换年份，日历展示对应年份各月的支出总和
* 支持账本多选筛选，同时查看多个账本的支出
* 点击月份格子可查看该月每日账单，点击账单可查看详情、编辑或发起退款
